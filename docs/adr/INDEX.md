# ADR 摘要索引

架构决策记录（Architecture Decision Record）。公开仓库只放这份索引：每条一行结论，正文（背景、备选方案、代价与实测数据）在维护者的私有仓库里。

标题即决策。编号在代码注释与文档里被直接引用，形如 `ADR-0003`。

---

### ADR-0001

**首版面向个人自托管，智能体能力显式启用**

部署形态限定为单人自托管、可接多个本人账号的网关，不做公共多租户或对外提供权益；默认走直连，智能体模式必须显式开启并在隔离环境中运行。

### ADR-0002

**个人部署也分离管理凭据与调用凭据**

管理与调用用两套凭据，避免把管理面暴露给普通调用方。已被 [ADR-0012](#adr-0012) 取代：管理权限改为随有效调用凭据授予，管理口令降为可选加固。

### ADR-0003

**个人账号池自动调度，历史归属仍按调用凭据隔离**

同一实例可接多个上游账号并按会话绑定调度；上游账号是执行资源，调用凭据才是历史与用量的归属边界，相同会话 ID 不跨凭据合并。

### ADR-0004

**换号限于可安全迁移且尚未交付内容的请求**

只有权限与模型匹配、上下文可完整重建、无账号专属状态且尚未交付内容时才跨账号重试；一旦产出回答、推理或工具调用，失败就明确返回，不重放。

### ADR-0005

**发布桥接层镜像，模拟回归与真实验收分开**

正式镜像只含桥接层，不装官方 CLI；普通提交用模拟上游跑回归，发布前再在获授权环境做真实客户端烟测，两类证据分开记录。

### ADR-0006

**Web 面板集成设备授权流与动态账号池运维**

控制台可直接发起官方 OAuth 设备授权并管理账号生命周期，同时保留宿主机只读挂载的账号；两类账号同池调度，写操作受管理凭据保护。

### ADR-0007

**UI 优化锁定正式版控制台，上一版原型归档后移除**

只优化在运行的那个页面；旧原型先完整归档再删除，避免两套 UI 概念长期并存。

### ADR-0008

**控制台改为运维仪表盘优先，并以点击数、可发现性、零回归验收**

首屏服务部署者的运维任务（账号池、用量与成本、模型），对话退为次要视图；验收以真实服务做前后基线，不引入前端构建。

### ADR-0009

**调用凭据可读部署级只读仪表盘**

新增只读聚合接口，任何有效调用凭据都能读部署级用量与积分；代价是共享 key 等于共享账单可见性，响应必须剔除令牌类字段。

### ADR-0010

**只持久化上游刷新令牌，按需换取短期 JWT 读取积分**

刷新令牌落在数据卷内 `0600` 的文件中，仅用于只读查询积分，绝不返回前端、绝不写日志；换取 JWT 时自动轮换并做单飞刷新。

### ADR-0011

**控制台改为左侧 TAB 导航，并让 credits 成为唯一额度口径**

导航固定为左侧标签页，同一时刻只渲染一个视图；额度统一用 credits 表达，不再并列多套计数。

### ADR-0012

**管理权限随调用凭据授予，管理口令降为可选加固**

未设 `ADMIN_PASSWORD` 时，持有任一有效调用凭据即可管理；设置后管理操作额外要求口令校验，调用凭据不能顶替。

### ADR-0013

**运行时配置与设置页范围**

新增数据卷内的运行时配置文件，页面写入、服务端按请求读取；`process.env` 只作初始默认值，未知键忽略、越界整体拒绝。

### ADR-0014

**按代码评审结论整改：假开关、超时语义与用量契约**

把「页面能改、行为不变」的开关接回调度侧，区分总时长与流空闲两种超时，并重新校准用量接口的鉴权口径。

### ADR-0015

**第二轮评审整改：空闲超时、倍率来源与统计重置端点**

流空闲超时改为相邻数据块之间的间隔，倍率来源可追溯，新增仅管理面可用的统计重置端点。

### ADR-0016

**账号池表格化与独立的用量视图**

账号池改用表格呈现，用量从浮层拆成独立视图；上游没有对应接口的运营开关一律不出现，不用假按钮凑数。

### ADR-0017

**用量账本：分桶维度、窗口口径与保留**

一个桶是「时间片 × 账号 × 模型 × 倍率 × 调用凭据」；小时桶保留 90 天，更早的折叠成日桶永久保留，合计口径始终包含日桶。

### ADR-0018

**运行时重绑监听地址：先起新再关旧与失败回滚**

换监听地址时新建 server 并重挂 WebSocket upgrade，成功后才落盘；新地址起不来就返回 409 并保留原监听。

### ADR-0019

**接入配置是派生值：为什么不给调用凭据加字段**

接入地址、key、账号范围与模型都在渲染时算出，不新增存储与迁移，也就不存在需要与凭据同步的「配置」实体。

### ADR-0020

**用量趋势图：双轴堆叠柱，粒度自动但只到小时**

左轴 token、右轴请求数，粒度按区间自动选择；图表库固定版本并加完整性校验，加载失败时降级为表格。

### ADR-0021

**Tool Search：消费并留痕，工具前置加载，不做网关内模拟**

上游的 tool search 一族整体消费并记日志，以工具前置加载等价替代，不在网关里模拟一套检索。

### ADR-0022

**思考强度统一档位：三协议入站归一与上游方言出站**

三种客户端方言先归一成内部六档（off/minimal/low/medium/high/xhigh），再翻成上游方言；映射集中在单一模块。

### ADR-0023

**README 面向首次部署重写，深度内容分流到 docs/**

README 只负责让首次部署者快速跑通，配置细节、接口语义、排障与客户端接入分流到 `docs/`，索引按「我想做什么」组织。

### ADR-0024

**公开仓由私有仓导出，ADR 只对外提供摘要**

私有仓保存全部内容与历史，公开仓由脚本按白名单导出、独立建历史；ADR 对外只放「编号 + 标题 + 一句话结论」的索引，正文与实测数据留在私有仓。
